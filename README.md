# ✖️ Multiplication Game

A fun and interactive Multiplication Game built using HTML, CSS, and JavaScript.
This game helps users improve their multiplication skills through simple and engaging gameplay.

---

## 📌 Features

* Random multiplication questions
* Score tracking system
* Interactive gameplay
* Responsive design
* Simple and clean user interface
* Instant answer feedback

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
